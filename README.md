# astrbot_plugin_cet_wordbook · 四六级词书

给 AstrBot 用的四六级背单词插件：**定时推送单词、可配置间隔和休息时间、自动小测、错题本自动回收**。

不需要额外的 LLM 调用，纯本地词表 + 定时调度，几乎不占资源。

## 功能

- **双词书**：四级 2607 词 / 六级 2345 词，随时切换
- **定时推送**：每小时 / 每 N 小时 / 每 N 分钟，自动摊平到活跃时段
- **每日定量**：每天发多少个词由你定，按间隔均分到每个时段
- **休息时间**：默认 8:00–22:00，窗口外不发
- **自动小测**：每天 N 道选择题，可固定时间（如 21:00），也可均匀分布
- **可选题源**：考「今日单词」或「整本词书」
- **错题本**：答错自动记录，并把该词**放回词池**，之后还会被抽到
- **错题本推送**：每 N 天自动推送一次，间隔可改
- **指令操作**：切词书、立刻抽词、立刻小测、查错题本，不用改配置

## 安装

1. 把整个 `astrbot_plugin_cet_wordbook` 目录放进 AstrBot 的 `data/plugins/` 下
2. 重启 AstrBot，或在 WebUI 插件页重载
3. 插件配置在 WebUI → 插件 → 四六级词书 → 齿轮

无第三方依赖，词表已内置在 `books/` 下（来源见文末）。

## 配置项

| 配置 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `wordbook` | 选项 | 四级 | 词书：四级 / 六级 |
| `words_per_day` | 整数 | 20 | 每天推送的单词总数 |
| `send_mode` | 选项 | 每小时 | 每小时 / 每N小时 / 每N分钟 |
| `interval_value` | 整数 | 1 | 「每N小时」「每N分钟」里的 N |
| `rest_start` | 整数 | 8 | 开始发送的小时（24 小时制） |
| `rest_end` | 整数 | 22 | 停止发送的小时 |
| `quizzes_per_day` | 整数 | 3 | 每天小测题数，0 关闭 |
| `quiz_batch` | 整数 | 1 | 每条小测消息含几题 |
| `quiz_source` | 选项 | 整本词书 | 出题范围：今日单词 / 整本词书 |
| `quiz_time` | 整数 | 0 | 0=全天均匀；1–23=固定在几点出题 |
| `wrongbook_days` | 整数 | 7 | 每多少天推送一次错题本，0 关闭 |
| `target_session` | 文本 | 空 | 推送会话（UMO）；留空自动用最近一次私聊会话 |

### 间隔与数量怎么算

假设 `rest_start=8`、`rest_end=22`、`send_mode=每小时`、`words_per_day=20`：

```
活跃时段 = 14 小时 → 14 个时段
20 个词均分 → 每个时段约 2 个词
```

如果改成 `每N分钟`、`interval_value=30`：

```
840 分钟 / 30 = 28 个时段 → 每时段 1 个词
```

## 指令

| 指令 | 说明 |
| --- | --- |
| `/词书 四` `/词书 六` | 切换词书 |
| `/词书状态` | 查看当前配置和今日进度 |
| `/单词 [n]` | 立刻随机抽 n 个词（默认 1） |
| `/小测 [n]` | 立刻出 n 道题（默认取配置） |
| `/错题本` | 查看错题本 |

指令需要管理员权限。小测答题格式：`1A 2B`，单题直接回 `A`。

## 工作方式

### 时段调度

插件每 20 秒检查一次，按配置生成当天的时间槽：

- 单词槽：活跃时段内按间隔切开，单词均分到各槽
- 小测槽：`quiz_time=0` 时均匀分布；填了小时就固定在那个点
- 已经错过超过 3 小时的槽**不补发**，避免重启后一次性刷屏

### 今日单词

`quiz_source=今日单词` 时，只从**当天推送过的词**里出题；当天还没推送过词时，自动回退到整本词书。

### 错题回池

答错后：

1. 词条写入错题本（记录次数、释义、词书、最后答错时间）
2. 该词重新塞回随机队列，之后还会被抽到，直到答对

### 错题本推送

`wrongbook_days` 天没推送过、且错题本非空时，自动推送一次全部错题。

## 数据文件

运行数据在 `data/plugin_data/cet_wordbook/`：

| 文件 | 内容 |
| --- | --- |
| `state.json` | 当天时间槽、词池队列、待答小测、最近会话 |
| `wrongbook.json` | 错题本 |

词表内置在插件目录 `books/cet4.json`、`books/cet6.json`。

## 常见问题

**重启后今天没收到单词？**
已经过点的时间槽不会补发，第二天按配置继续。

**为什么一直不推送？**
需要先私聊机器人一次，让它记住会话；或在配置里填 `target_session`。

**固定时间不生效？**
`quiz_time` 必须落在 `rest_start`–`rest_end` 之间。

**想完全复刻旧的 21:00 小测？**
设 `quiz_source=今日单词`、`quiz_time=21`。
